视角与控制来源注意事项

以下按键作用于模拟器窗口。若网页正在接管，先点“撤销并停止”或在模拟器按 Esc，再使用本地控制。

视角与己方机器人

  • F3：自由观察 → 第一人称 → 第三人称 → 自由观察。本地驾驶使用第一／第三人称；网页全手动驾驶不受模拟器观察视角限制。
  • W A S D：移动车辆；左 Shift：加速；方向键：手动云台。
  • Q：切换己方小陀螺；F5：切换自瞄。当前 Q 是开关，不是旧说明中的 Q/E 左右转。
  • Space：手动模式射击；自瞄模式按住授权自动射击，松开撤销。开启自瞄时方向键不接管云台。
  • Esc：撤销网页控制，关闭自瞄和小陀螺，恢复本地手动。
  • F2：截图；G：触发场景飞镖发射（需场景具备相应对象）。

自由观察相机

W A S D 移动相机，Space 上升，左 Ctrl 下降，按住鼠标右键并移动鼠标改变朝向。此视角屏蔽本地机器人和靶车输入，关闭本地自瞄与己方小陀螺；网页已有的远端控制仍有效。观察相机与网页驾驶互不占用输入。

测试靶车／假人

Tab 切换当前靶车；I J K L 移动，右 Shift 加速；U 切换靶车小陀螺；C / B 调整云台水平、F / V 调整俯仰。[ / ] 和 ; / ' 调整靶车底盘倾斜。

靶车控制只在第一／第三人称下生效；自由相机不再使用 J 下降，避免同时移动靶车。

Xbox 手柄（连接模拟器）

左摇杆移动车辆，按左摇杆加速；右摇杆调整云台，LT 精细瞄准；LB 切换己方小陀螺。按住 RT 开启自瞄，RB 手动射击／自瞄时授权射击。View 切换视角，Menu/Start 切换靶车，十字键移动靶车，Y 切换靶车小陀螺，按住右摇杆并推动可调靶车倾斜，X 触发飞镖。

手柄产生有效输入后接管本地自瞄来源并清除键盘 F5 的锁定状态：松开 RT 即退出手柄自瞄。再次使用键盘控制则切回键盘来源，需要重新按 F5 开启。网页接管时以网页状态为准。手柄说明采用 Xbox 标识。

官方协议模式（RMU 裁判系统）

“显示链路”选“官方图传”或“自定义链路 0x0310”即进入此模式，服务端开启 RMU 时自动选中官方图传。画面上方是比赛阶段、倒计时、双方基地/前哨，左右是双方 5 台机器人血量（官方 GlobalUnitStatus 下发），底部是本机血量、热量、发弹量、经济。

自定义链路 0x0310 是机器人经图传链路发来的 300 字节 × 50 Hz 数据块（约 120 kbit/s，无重传），这里用来传低码率画面：分辨率低、偶有花屏属正常，用于官方图传不可用或需要机器人端自选画面时。

点右侧“接管键鼠”后画面出现黄框，点击画面锁定鼠标，边框变青色即“正在控制”：WASD、Shift、Ctrl、Q E R F G Z X C V B、鼠标移动/左右中键/滚轮按手册位掩码以 75Hz 发送。Esc 释放鼠标并清零输入，再按一次 Esc 撤销接管。比赛时键鼠来源只能在官方选手端和自定义客户端之间二选一。

右侧小地图点击发送地图标记；常用指令直接点按钮，其余收在折叠栏里。码率、丢块、键鼠帧数等调试数据在最下方“诊断”。

网页操作与图传 · 1. 开始操作

全屏驾驶：点击顶部“全屏驾驶”，将放大画面并收起图传调参和小地图。右上角“操作说明”仍可随时展开，主画面会为抽屉让出空间。全屏不会自动接管机器人；选择全手动并接管后键盘锁定。退出全屏会撤销网页控制，重新进入需要再次接管。

全屏只简化显示，不提高源画面帧率。当前源约5Hz；H.264丢包还可能等待关键帧恢复。车辆移动跟随云台朝向，松键后的减速受模拟器物理影响。

确认右上角“模拟器在线”，选择控制方式，再点“接管模式控制”。观察右侧实际控制模式和实际状态，确认指令已生效。网页全手动可以在任意观察视角驾驶；模拟器 F3 随时切换观察视角。

2. 指挥模式

在网页切换自瞄、小陀螺。开启自瞄后，按住“授权自动射击”按钮才允许车端根据 FireGate 决定是否射击，松开撤销。驾驶仍由模拟器键盘／手柄完成。

3. 全手动接管

全手动接管后自动进入键盘已捕获：W A S D 移动，方向键 调整云台，按住 J 发射，无需再点任何“锁定”按钮。驾驶期间网页会拦截这些键以及 Space，因此页面不会滚动；Space 在网页不触发射击（原生模拟器仍用 Space）。Esc 撤销控制。点击输入框/下拉框时暂停捕获，改完自动恢复。

浏览器按键：网页不绑定 F2/F3/F5；F3 查找、F5 刷新仍是浏览器功能。模拟器视角切换和本地自瞄按键只在原生模拟器窗口有效。Ctrl/Alt/Meta 组合键不发送驾驶命令；驾驶区内 Esc 撤销网页控制。

4. 停止与接管

点“撤销并停止”退出网页控制；回到模拟器按 Esc 可恢复本地手动控制。网页失焦清空按键与射击，切换标签或心跳中断后控制会超时撤销，返回需重新接管。

5. 图传压缩测试

JPEG：调整宽度、质量、FPS和载荷预算，观察清晰度与更新速度。

H.264：建议先选 80 kbit/s、40包/秒、0%丢包，再点“应用 H.264 测试配置”。可切回原 JPEG 对比，随后增加丢包率，观察画面年龄和恢复时间。

H.264 当前为320×240、12FPS目标，源快照约5Hz；300B×40/50Hz分别为96/120 kbit/s包载荷上限。画面停住时查看“解码画面年龄”，等待关键帧可能导致冻结。测试链延迟不含源采集和浏览器显示。

6. 小地图与故障提示

小地图显示模拟器自车真值，青色是底盘方向，黄色是云台方向，网格2米。它尚无场地底图、敌方观测和点击导航。

画面离线时检查 Web 桥接；能跟踪却不射击时，检查实际授权、桥接启动参数 -Send -AllowFire 和算法调试页中的 FireGate。不要同时启动多个图像桥。

说明为非模态抽屉，可保持展开并用方向键操作；打开说明会清空当前按键，避免残留输入。
