# NHS Server 与 Daedalus 操作说明

NHS Server 是操作手终端，Daedalus 是模拟器。网页右上角“操作说明”包含本说明的交互版本。

## 选择控制方式

- 本地：模拟器窗口操作，F3 切到第一／第三人称。
- 网页指挥：点击接管，网页管理自瞄、小陀螺和射击授权；本地负责驾驶。
- 网页全手动：点击接管后自动捕获键盘，用 WASD 移动、方向键云台、J 射击（已取消网页Space射击）。
  自动化关闭，本地车体输入被覆盖；模拟器观察视角不再限制网页驾驶，F3仍可使用。
- 模拟器 Esc：撤销远端会话、关闭己方自动化，恢复本地手动。

## 模拟器键盘

| 按键 | 驾驶视角功能 |
|---|---|
| F3 | 自由观察→第一人称→第三人称循环 |
| WASD / 左Shift | 己方移动 / 加速 |
| 方向键 | 手动云台（自瞄开启时不生效） |
| Q / F5 | 己方小陀螺开关 / 自瞄开关 |
| Space | 手动射击；自瞄时按住授权自动射击 |
| Tab | 切换当前靶车 |
| IJKL / 右Shift | 靶车移动 / 加速 |
| U | 靶车小陀螺开关 |
| C、B / F、V | 靶车云台水平 / 俯仰 |
| [、] / ;、' | 靶车底盘倾斜 |
| F2 / G | 截图 / 场景飞镖发射 |

自由观察：WASD移动相机，Space上升，左Ctrl下降，按住鼠标右键旋转。
该视角屏蔽本地己方与靶车控制输入，关闭本地自瞄和己方小陀螺。
远端网页控制仍可执行；靶车已有运动状态不代表场景被暂停。

## Xbox 手柄

左摇杆移动，L3加速；右摇杆云台，LT精瞄；LB己方小陀螺。
RT按住自瞄，RB射击／自瞄时授权。View切视角，Menu/Start切靶车，
十字键移动靶车，Y靶车小陀螺，R3+右摇杆调靶车倾斜，X飞镖。
自由观察仅保留手柄视角切换。

有效手柄输入清除F5锁定，RT松开即退出自瞄；切回键盘后需重新F5开启。
不要同时操作两套设备；当前帧同时输入时，采样顺序让有效手柄输入优先选择自瞄来源。
网页控制优先于本地自瞄来源。

## 图传与退出

JPEG调节宽度、质量、FPS和预算；H.264从80kbit/s、40包/s、0%丢包开始，点击应用。
关注解码画面年龄与恢复时间，不把旧画面当实时。小地图是自车模拟真值。
网页失焦清空按键与射击，隐藏或心跳中断后租约到期撤销。打开操作说明会释放移动和射击输入。

## RMU2026 自定义操作手终端

终端同时支持模拟器模式和 RMU2026 V2.0.0 自定义客户端模式。比赛部署应使用
Linux，并在 `operator_config.json` 中选择 `"mode": "rmu"`，或直接运行：

```bash
./run_operator.sh
```

RMU 模式使用机器人 ID 作为 MQTT clientID，连接 `192.168.12.1:3333`，并在 UDP
3334 接收 HEVC 图传。打开页面后，将视频源切换为“裁判系统图传”；接管按钮明确
开启后才会发送 KeyboardMouseControl，释放接管、连接断开或输入超过 250 ms 未刷新
都会发送零输入。地图点击、哨兵、飞镖和性能选择等命令受客户端速率限制。

本机联调可运行 `./run_operator.sh --mock`（Windows 下为
`Start.bat -Mode rmu-mock`）。Mock broker 仅绑定 127.0.0.1 且无认证；真实 MQTT
链路按协议无用户名、密码和 TLS。客户端 UDP 3334 默认绑定 `0.0.0.0`，请在比赛
网络中用防火墙限制来源。

协议实现位于 `tools/rmu_protocol/`，包含手册字段校验、MQTT 链路、3334 分片重组、
HEVC 解码和 Mock 引擎。`RadarInfoToClient` 的字段布局、MapClick 坐标单位/字段
语义以及鼠标滚轮灵敏度仍需用真实裁判系统抓包确认；当前 Mock 不能替代实机联调。

本次未增加鼠标云台瞄准、键位自定义和靶车运动预设。

## 全屏驾驶

顶部“全屏驾驶”使用浏览器原生全屏：放大画面，收起视频调参和小地图，保留模式控制与操作说明入口。
说明抽屉在全屏中仍能展开，画面为其让出空间。全屏不自动接管机器人。
已处于全手动接管时进入全屏会继续捕获键盘；退出全屏撤销网页控制。
浏览器可能保留Esc退出全屏行为，按键处理和fullscreenchange都会执行释放/撤销。

手感排查：当前源快照约5Hz，HTTP控制心跳100ms、UDP中继周期至少50ms，均可能影响响应。
模拟器VehicleDynamic零输入仅不再施加推力，未实现主动制动；实际减速由物理阻尼/摩擦等决定。
WASD以云台GlobalTransform为参照。后续应分别比较原生视角、本地驾驶与网页驾驶，再调整制动和控制采样。

## 网页说明抽屉与浏览器快捷键

操作说明是右侧非模态抽屉：宽屏给说明预留空间，窄屏在页面内展开，不盖住控制按钮。
全手动接管后自动捕获键盘，无需任何“锁定”按钮，也不依赖驾驶区DOM焦点。
捕获期间在捕获阶段拦截WASD、方向键、J，并阻止Space的默认滚动；Space不绑定网页射击。
点击输入框/下拉框会暂停捕获，改完自动恢复。点击说明会清空按键但保持接管。
F2/F3/F5仅为原生模拟器窗口按键，网页保留浏览器查找/刷新行为，不透传。
Ctrl/Alt/Meta组合键不触发驾驶，进入组合键或功能键时释放已有驾驶输入。
捕获时Esc撤销网页控制；模拟器窗口Esc按本地接管逻辑执行。
切出浏览器会清空按键，返回后仍保持接管；不会强抢地址栏或系统焦点。
页面轮询会检测 UI 版本变化并自动刷新，避免旧缓存导致按键无效。
