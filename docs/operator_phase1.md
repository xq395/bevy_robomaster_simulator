# 第一阶段：操作手授权与统一发射入口

## 使用

- F5：切换自瞄；Q：切换小陀螺，彼此独立。
- 手动模式：Space / 手柄 RB 直接请求发射。
- 自瞄模式：按住 Space / RB 授权自动射击，松开撤销；不能绕过桥接 FireGate。
- Esc：撤销远端会话并恢复本地手动控制。
- 本地控制时窗口失焦撤销控制状态；远端控制不受模拟器窗口失焦影响。
  远端授权超时撤销，恢复连接必须重新查询会话并明确授权。
- 底部 HUD 显示授权、控制来源、已应用序号、执行结果。
- C++ 桥仍需 `-Send -AllowFire` 才会提供可执行的射击建议。

统一发射入口每帧执行一次并推进冷却计时。Talos 命令先检查有限值、距离、
时间戳（200ms）、重复和授权切换边界，再检查角度可达性并更新云台，最后提交射击建议。
只有当前授权与建议同时有效，才执行自动射击。弹量、热量本阶段未模拟。
桥接遥测 `fire` 仍表示建议；实际发射看模拟器 `shot_count` 与弹丸统计。

## 本地开发接口

UDP `127.0.0.1:5001`，与赛事 MQTT/Protobuf 无关。仅有一个远端控制会话；
驾驶仍使用本地输入。发 `status` 获取 JSON 状态。控制 JSON 为：

```json
{"session":123,"seq":1,"sent_ms":123456789,"ttl_ms":300,"aim_enabled":true,"fire_authorized":false,"spin_enabled":false}
```

`session` 使用查询结果；`seq` 必须大于 `applied_seq`；`sent_ms` 是本机 Unix 毫秒，
有效期为 1–500ms。所有开关是设置值。重复/乱序不刷新有效期。
超时或接管更新会话，旧数据包不能重新授权。回包包含应用状态或拒绝原因。
`reason=applied` 表示控制层已接受，实际执行状态需再次查询。

```powershell
python tools/operator_control.py
python tools/operator_control.py --aim --seconds 10
python tools/operator_control.py --aim --authorize --spin --seconds 10
```

测试客户端每 50ms 刷新，有效期 300ms；结束时撤销。远端控制期间允许切到浏览器。
端口被占用时只禁用远端适配器，本地控制继续可用。

ROS2 旧接口当前没有已验证的命令新鲜度契约，本阶段只保留跟踪，禁止自动射击。
Windows 默认 Talos 路径为本阶段的验收目标。

## 验收

1. 自瞄开、未按 Space：跟踪但不射击。
2. 按住 Space：只有 FireGate 给出建议且射速冷却结束才射击。
3. 松开 Space / 按 Esc / 窗口失焦：撤销自动射击。
4. Q 切换不改变射击授权。
5. 发送重复、过期或旧会话指令：回包拒绝，已应用序号不前进。
6. 停止远端心跳：到期撤销，不重新使用旧自瞄建议。

自动检查：`cargo test --bin daedalus`。图形界面、真桥接和手柄行为仍需交互验收。

## 操作手可视化（第二阶段初版）

启动模拟器后，用 `tools/run_talos_web_debug.ps1 -Send -AllowFire` 启动唯一的桥接图像消费者，
再运行 `python tools/operator_web.py`，打开 `http://127.0.0.1:5002/`。
不要同时运行普通桥和 Web 桥。页面复用 5000 端口 `/snapshot/raw` 快照，不读取图像三缓冲。

- 点击“接管模式控制”，再切换自瞄、小陀螺；按住射击按钮授权。页面默认进入全手动（操作手），可再切换到指挥。
- 页面每 50ms 更新意图；服务端持有浏览器意图，每轮以单调递增 `seq` 续租，租约 `ttl_ms=250`，因此连续驾驶期间不会自行过期。
- 中继在连接被 ICMP 端口不可达（`[WinError 10054]`）破坏时会重建 UDP 套接字，模拟器重启后可自愈，无需重启中继。
- 页面隐藏、服务断连或模拟器 Esc 接管后，需要重新显式接管。
- 显示请求状态和实际状态、序号、发射数与遥测年龄。
- 小地图使用 Bevy 世界 X/Z 平面，网格 2m，自车居中；青色为底盘方向，黄色为云台方向。
  数据明确标记为模拟器真值。目前没有场地底图、敌方观测或地图导航功能。
- 相机是约 5Hz 调试快照，非赛事图传或全帧率操作视频。

已实测 HTTP 状态查询、非射击模式控制生效、浏览器心跳停止后的超时撤销，以及图像代理返回 200。

### 压缩与模式扩展

- 指挥模式：控制自动化开关和射击授权，移动由模拟器本地输入承担；本地射击键不能绕过远端授权。
- 全手动：浏览器 WASD 移动、方向键云台、J 射击（网页空格不再绑定，避免与原生 Space 冲突）。
  模拟器应处于第一/第三人称驾驶视角（F3），不是自由观察相机。
  此模式覆盖本地车体输入，强制关闭自瞄、自动射击授权和小陀螺；切换模式清空输入。
- 页面失焦清空按键与射击；页面隐藏或心跳超时撤销控制。
- 视频支持宽度 320/640/960/1280、JPEG质量 5–90、请求帧率 2/5/10。
  源仍约 5Hz，10Hz 不能增加源的独立帧数。
- 120/256/512 kbit/s 为 HTTP JPEG 载荷的请求/显示节拍预算：大帧会降低更新频率。
  不包含 HTTP/TCP 开销，不实现赛事300B分片、丢包或物理链路整形，也不是H.265编码。
- 当前场景实测：320宽/Q15约1002B，1280宽/Q85约18951B；仅为当时画面的示例，随场景变化。
